Claude Tag is a Slack integration that runs
@Claude
in your team’s channels as your organization’s shared identity with admin-configured access. Anyone in a channel can tag
@Claude
into a thread and assign it a task. Read the
Claude Tag documentation
on claude.com to set it up and start using it.
Claude Tag is available on Team and Enterprise plans, and is distinct from the earlier
Claude Code in Slack
, which runs each session under an individual user’s account. On Pro and Max plans, where Claude Tag isn’t available, Claude Code in Slack remains the setup path.
